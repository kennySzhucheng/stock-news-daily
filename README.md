# 股市情报助手 · 项目总览

> 每天自动收集时事新闻 → AI 分析 → 网页日报 + 微信推送。**定位是信息助手，不提供买卖建议，决策权归用户本人。**

## 一、项目定位与边界

- 服务对象：有意进入 A 股的新手（使用广发易淘金App看行情与交易）
- 本工具职责：**搜集 → 筛选 → 分析视角 → 风险提示**
- 本工具不做的事：
  - 不给出"买入/卖出"指令，只呈现分析视角和不确定性
  - 不保证新闻解读正确，所有 AI 结论标注置信度
  - 不接入实盘交易

## 二、总体架构

```
┌─ GitHub Actions（云端定时）
│    每天两次：08:10 盘前任务 / 15:40 盘后任务
│
│   [M1 新闻收集] → 多源抓取原始新闻
│   [M2 新闻筛选] → 免费模型（GLM-4-Flash）：分类、去重、提取关联板块/个股
│   [M3 深度分析] → DeepSeek：市场情绪、板块逻辑、关注视角、风险提示
│   [M4 行情佐证] → 东方财富公开接口，抓取被提及个股的当前行情
│   [M5 日报生成] → HTML 网页日报 → GitHub Pages 可访问
│   [M6 手机推送] → Server酱 → 微信收到当日摘要
│
└─ 手机端：浏览器看 GitHub Pages 日报 / 微信收推送摘要
```

## 四、新闻来源策略（对应"多元化 + 准确性"要求）

### 4.1 多元化：不限财经垂直媒体

| 类别 | 来源 | 类型 |
|---|---|---|
| 财经快讯 | 新浪财经7×24、东方财富快讯 | 已验证可用 |
| 主流综合 | 新华网、人民网 | 政策/宏观权威 |
| 科技/产业 | 36氪、量子位 | 影响科技板块 |
| 国际视角 | 路透中文、参考消息 | 外围市场联动 |
| 政府发布 | 发改委、央行、证监会官网 | 官方口径最准 |

> 原则：**同一事件，至少两个独立来源交叉印证**，才算"确认"；单一来源标"待核实"。

### 4.2 准确性保障机制

1. **多源交叉验证**：两条以上独立来源报道同一事件 → `已确认`；否则 → `单源待核实`
2. **官方优先**：政策类新闻以政府官网原文为最高权重
3. **时间标注**：每条新闻都带原始时间戳，防止旧闻当新闻
4. **AI 不创作事实**：分析模型只允许基于收集到的原文，不得补充自己"知道"的未经核实的消息
5. **来源留痕**：日报中每条新闻附原始链接，用户可自行核对

